# Logs locais

Os logs brutos produzidos nas VMs não foram enviados junto de fotos.zip. Esta pasta não contém logs de execução. As saídas no relatório são transcrições das capturas.

Arquivos de resultados são ignorados pelo Git, exceto este README. Preserve originais em local privado e revise os trechos antes de publicar. Não publique cookies, tokens, arquivos HAR ou senhas pessoais.
